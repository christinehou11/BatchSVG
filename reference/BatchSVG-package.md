# Identify Batch-Biased Features in Spatially Variable Genes

`BatchSVG` is a method to identify batch-biased spatially variable genes
(SVGs) in spatial transcriptomics data. The batch variable can be
defined as sample, donor sex, or other batch effects of interest. The
BatchSVG method is based on the binomial deviance model (Townes et al,
2019).
